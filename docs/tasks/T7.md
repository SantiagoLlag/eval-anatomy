# T7 — Launch polish and deploy

**Depends on:** T3, T4, T5, T6. **Branch:** `t7-launch`.

## Goal
Production-ready public site.

## Deliverables
1. Home page `/[locale]`: one-screen explanation of what an eval is (from `anatomy.json` groups and running example), three entry points (Anatomy, Catalog, Inspect), a small live anatomy preview.
2. Accessibility audit (WCAG 2.1 AA) of every route, both themes, 375 px; fix findings.
3. Performance: diagrams lazy-loaded; Lighthouse performance ≥ 90 on `/es` and `/es/anatomy`.
4. Metadata: titles, descriptions, Open Graph images per route and per catalog eval, `sitemap.xml`, `robots.txt`.
5. README screenshots (es and en) and a 30-second GIF of /inspect.
6. Vercel project config notes in `docs/DEPLOY.md` (env vars, which features need a key). Do not deploy production yourself unless the issue says so; open the PR with a preview URL.

## Acceptance
- CI green; preview deployment works without any API key (LLM buttons hidden with an explanation).
