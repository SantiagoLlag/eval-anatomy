# T1 — App foundation

**Depends on:** nothing. **Blocks:** all other tasks. **Branch:** `t1-foundation`.

## Goal
A running, deployable Next.js app skeleton that loads the generated content and the catalog, in Spanish and English, with CI.

## Read first
`CLAUDE.md`, `docs/ARCHITECTURE.md` (Stack, Content model, Routes, Conventions), `schema/eval.schema.json`, `content/*.json`, `catalog/*/eval.md`, `docs/reference/agents-visualizer/package.json` (versions that worked in the sibling project).

## Deliverables
1. Next.js app (latest major, App Router, `src/` dir) with TypeScript strict, Tailwind v4, shadcn/ui initialised, ESLint, vitest. `docs/reference/**` and `research/**` excluded from tsconfig, lint and tests.
2. i18n: `src/app/[locale]/…` with `es` (default) and `en`; locale detection + header switcher; `messages/es.json`, `messages/en.json`. Use `next-intl` if it supports the installed Next major, otherwise a minimal typed dictionary helper.
3. `src/lib/content.ts`: typed loaders for `content/anatomy.json`, `taxonomy.json`, `best-practices.json`, `tools.json`, `sources.json` (zod schemas for each; fail the build if they do not parse). Helper `t(bilingual, locale)`.
4. `src/lib/schema/eval.ts`: zod `EvalCard` mirroring `schema/eval.schema.json` exactly. Test that the zod object keys equal the JSON Schema properties (recursively) so they cannot drift.
5. `src/lib/catalog.ts`: reads `catalog/*/eval.md` at build time (gray-matter + yaml), validates with zod, returns `{card, body, dir}`. `npm run validate:catalog` runs the same validation plus JSON Schema validation (ajv) and checks `id` equals the folder name; exits non-zero on any error.
6. Placeholder pages for every route in ARCHITECTURE.md (`/`, `/anatomy`, `/catalog`, `/catalog/[id]` statically generated, `/inspect`, `/sources`). `/sources` fully implemented: table of `sources.json` with title, authors, evidence level, status and link, filterable by lens.
7. Layout shell: header (logo text "eval-anatomy", nav, language switcher, GitHub link), footer (licenses: code MIT, content CC BY 4.0), light/dark via `prefers-color-scheme` + toggle, mobile-first.
8. Design tokens: one colour per anatomy group (5) and per grader kind (5), defined once as CSS variables; contrast-checked in both themes.
9. GitHub Actions `ci.yml`: `npm ci`, `npm run lint`, `npm test`, `npm run validate:catalog`, `npm run build` on push and PR.
10. `vercel.json` only if needed; `.env.example` with `ANTHROPIC_API_KEY=`, `AI_GATEWAY_API_KEY=`, `EVAL_ANATOMY_MODEL=claude-sonnet-5-5`.

## Acceptance
- `npm run build` succeeds; `/es/sources` and `/en/sources` render all sources.
- `npm run validate:catalog` passes on the two seed evals and fails on a deliberately broken copy (test it, then delete the copy).
- CI green on the PR.

## Out of scope
Diagrams, importers, linter, LLM routes.
