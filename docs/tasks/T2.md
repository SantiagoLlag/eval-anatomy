# T2 — Importers, coverage and LLM decomposition

**Depends on:** T1. **Blocks:** T4, T5, T6. **Branch:** `t2-importers`.

## Goal
Turn any supported eval file — or free text — into a `DecomposedEval` (see ARCHITECTURE.md "Core in-memory model"), with per-part coverage.

## Read first
`docs/ARCHITECTURE.md` (Core in-memory model, coverage table, Importers, LLM features and keys), `content/tools.json` (field names per tool, detection signals, notes), `research/fixtures/*` (the same eval in 10 formats), `catalog/*/eval.md`, `docs/reference/agents-visualizer/src/lib/importers/*` and `src/lib/llm/client.ts` (patterns).

## Deliverables
1. `src/lib/coverage.ts`: `computeCoverage(card, anatomy, taxonomy)` implementing the coverage table as data. One test per row (present / partial / missing / not-applicable).
2. `src/lib/importers/detect.ts`: `detectFormat({name, text})` → ranked candidates with scores and matched signals.
3. Parsers (each returns `DecomposedEval`, records `from` for every filled part, never invents fields):
   - `canonical` (eval.md)
   - `vault-evals`: Markdown with frontmatter (`id, nombre, version, estado, dimension, aplica_a, modo, fuentes, gates`) and 8 numbered `##` sections, the "Preguntas" table with columns `id | Pregunta | Qué evidencia buscar | Ejemplo PASS | Ejemplo FAIL | Principio y ficha | es_gate`, an "Anclas" section and "Reglas NA y UNKNOWN". Use the catalog seeds' `source_format: vault-evals` cards as the expected mapping reference.
   - `promptfoo`, `openai-evals-registry` (YAML + JSONL), `openai-evals-api` (JSON), `lm-eval` (YAML with `!function` tolerated), `elevenlabs` (JSON; ignore `"//"` comment keys).
   - Best-effort static parsers: `inspect` (`Task(dataset=…, solver=…, scorer=…)`), `deepeval` (`LLMTestCase`, `GEval(criteria=…, evaluation_steps=…)`, `threshold`), `braintrust` (`Eval(…, data=…, task=…, scores=[…])`).
4. `POST /api/decompose`: free text (≤ 50 kB) → `generateObject` with a zod schema = `EvalCard` + per-part `{status, from}`. System prompt: map only what is stated; absent parts stay absent; quote the source span in `from`. Key resolution as in ARCHITECTURE.md. Rate-limit per IP in memory. Return 400 on oversize, 503 when no key.
5. `src/lib/exporters/canonical.ts`: `DecomposedEval → eval.md` text (frontmatter + body), round-trip tested against the two seeds.
6. Tests: each fixture in `research/fixtures/` imports with a coverage snapshot; detection picks the right format for every fixture and for both seeds; the decompose route is tested with a mocked model.

## Acceptance
- All fixtures and seeds import with no thrown errors; snapshots reviewed by hand once (note anything surprising in the PR).
- `promptfoo.yaml` fixture yields criteria, graders (code + llm-judge), reference and threshold present; purpose `partial` (description only).

## Out of scope
UI beyond a minimal debug page `/[locale]/inspect?debug=1` that prints the JSON.
