# Reference: agent-architecture-studio (read-only)

Selected files from a sibling project by the same author that solved the same problems for agent architectures:
a zod schema, format importers with an LLM free-form fallback, a best-practices JSON generated from a research
vault with enforced traceability, a lint engine (deterministic + LLM judge), and an @xyflow/react canvas with
dagre auto-layout.

Use them as patterns. Do not import from this folder; it is excluded from build, lint and tests.
Versions that worked are in `package.json`. The model id in `src/lib/llm/client.ts` is outdated; use the one in `CLAUDE.md`.
